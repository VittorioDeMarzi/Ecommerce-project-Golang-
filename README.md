# Golang E-Commerce API

hands-on learning project for building a RESTful API for an E-commerce system, developed entirely in **Go (Golang)** following *Clean Architecture* and *12-Factor App* principles.

## Tech Stack and Libraries Used

The project aims to keep external dependencies to a minimum, heavily leveraging Go's powerful standard library, while integrating professional tools for data management:

* **`net/http` (Standard Library):** Used for the HTTP server and basic routing.
* **`log/slog` (Standard Library):** Used to implement *Structured Logging* (JSON formatted logs), which is essential for production monitoring.
* **[sqlc](https://sqlc.dev/):** A powerful tool that generates type-safe Go code from raw SQL queries, eliminating the need for a heavy ORM.
* **[golang-migrate](https://github.com/golang-migrate/migrate):** A CLI tool used for managing database schema migrations (creating and updating tables).
* **PostgreSQL / MySQL:** The relational database used for the persistent storage of products and orders. (The project is typically configured for SQL interaction via native drivers like `lib/pq` or `go-sql-driver/mysql`).

## Architecture Structure

The project is structured following **Clean Architecture** principles:
* **Routing and Handlers:** Responsible exclusively for receiving HTTP requests, parsing JSON, and returning the appropriate responses.
* **Services (Business Logic):** The core of the application, where the business rules live (e.g., validating an order before creating it).
* **Storage / Repositories:** The isolated layer dedicated solely to communicating with the database (using the code generated by `sqlc`).

## Prerequisites

* [Go](https://go.dev/doc/install) (version 1.21+ recommended for full `log/slog` support).
* [Docker](https://www.docker.com/) (optional, but recommended for spinning up a local database).
* A local instance of PostgreSQL or MySQL.
* Local installation of the `migrate` CLI to run database migrations.
* Installation of `sqlc` (if you wish to modify or regenerate SQL queries).

## Setup and Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/golang-ecommerce-api.git](https://github.com/your-username/golang-ecommerce-api.git)
    cd golang-ecommerce-api
    ```

2.  **Database Setup:**
    Ensure your database is running. Create a database (e.g., `ecom`) and update the connection string (DSN) inside the project or your environment configuration file.

3.  **Run Migrations:**
    To create the tables in the database, run the migration tool:
    ```bash
    make migrate-up
    # Or by directly using the migrate CLI pointing to the /db folder
    ```

4.  **Download Go modules:**
    ```bash
    go mod tidy
    ```

5.  **Run the application:**
    ```bash
    go run main.go
    # Or via Makefile if configured: make run
    ```

## Main Endpoints (Example)

* `GET /products` - Returns the list of available products.
* `POST /orders` - Creates a new (simulated) order within the E-commerce platform.
